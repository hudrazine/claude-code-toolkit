# Claude Code Enhancement Toolkit

[![License: Unlicense](https://img.shields.io/badge/license-Unlicense-blue.svg)](http://unlicense.org/)

A comprehensive enhancement toolkit for Claude Code that extends its capabilities through native features (Memory management, Subagents, and Slash commands).

## Available Components

- **Memory Bank System** - Persistent context management across sessions  
- **Universal Agents** - Generic subagent templates for common tasks
- **Custom Commands** - Reusable slash commands for various tasks
- **Prompts Library** - Reusable prompt templates for CLAUDE.md

## Quick Start

1. Clone this repository
2. Copy the components you need to your project's `.claude/` directory
3. Import them in your `CLAUDE.md` file using `@import` syntax
4. Customize as needed for your specific use case
